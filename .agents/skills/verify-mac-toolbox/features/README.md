# Mac Toolbox feature map

The menu-bar toolbox icon is the user entry point. There is no normal app window.
Run the skill's doctor first; use one installed instance and exact English labels.
The harness opens, snapshots, and closes the menu using native Accessibility APIs.
It never presses setting toggles. Retain command/action evidence with the resulting
menu snapshot, and distinguish inspection from functional transition tests.

- [Display effects](display-effects.md): Color Filters and Night Shift, checkmarks, errors.
- [Built-in display control](built-in-display.md): automatic external-only mode and restoration.
- [Music blocking](music-blocking.md): independent Apple Music rule and status.
- [Login and quit](login-and-quit.md): launch registration and normal exit.

Real display changes from tests are prohibited by AGENTS.md. Hardware removal,
wake, Music termination, and login registration are not implied by a generic PR
verification request. Record unexercised journeys and their prerequisites; an AX
snapshot of a menu entry does not prove the corresponding side effect happened.
